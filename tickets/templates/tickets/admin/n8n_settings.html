Endpoints Disponíveis
Listar Tickets

GET /api/n8n/tickets/

Obtém uma lista de tickets com opções de filtro. Parâmetros de consulta suportados: status, empresa, categoria, prioridade.

Exemplo: /api/n8n/tickets/?status=aberto&empresa=1

Detalhes do Ticket

GET /api/n8n/tickets/{id}/

Obtém informações detalhadas sobre um ticket específico, incluindo seus comentários e histórico.

Atualizar Ticket

POST /api/n8n/tickets/{id}/update/

Atualiza informações de um ticket existente. Campos suportados: status, prioridade, titulo, descricao, categoria.

Adicionar Comentário

POST /api/n8n/tickets/{id}/comment/

Adiciona um novo comentário a um ticket. Campos obrigatórios: texto, autor_id.

Criar Ticket

POST /api/n8n/tickets/create/

Cria um novo ticket. Campos obrigatórios: titulo, descricao, empresa_id, criado_por_id.

Campos opcionais: prioridade, categoria_id, atribuido_a_id.

Guia de Integração com n8n
Este guia passo a passo irá ajudá-lo a configurar a integração entre o Helpdesk e o n8n para automação de fluxos de trabalho.
1. Pré-requisitos
  • Uma instância do n8n em execução (Guia de instalação do n8n)
  • Acesso de superusuário ao sistema Helpdesk
  • Conexão de rede entre o servidor Helpdesk e o servidor n8n
2. Configurando no n8n
A. Criar um webhook no n8n
  1. Acesse sua instância do n8n
  2. Crie um novo fluxo de trabalho clicando em "New Workflow"
  3. Adicione um nó "Webhook" do menu de nós
  4. Configure o webhook como "POST" para receber dados do Helpdesk
  5. Salve o workflow e ative o webhook clicando em "Active"
  6. Copie a URL do webhook (será parecida com https://seu-servidor-n8n.com/webhook/abc123...)
B. Processar dados recebidos
  1. Adicione um nó "Function" após o webhook para processar os dados
  2. Use código como o exemplo abaixo para manipular os dados recebidos:
// Exemplo de código para processar o evento recebido
const event = $input.item.json.event;
const data = $input.item.json.data;

// Verificar o tipo de evento
if (event === 'ticket_created') {
  // Processar criação de ticket
  return {
    json: {
      processed: true,
      eventType: event,
      ticketId: data.ticket ? data.ticket.id : null,
      message: `Novo ticket criado: ${data.ticket ? data.ticket.titulo : 'Desconhecido'}`
    }
  };
}

return {
  json: {
    processed: true,
    eventType: event,
    message: `Evento processado: ${event}`
  }
};
3. Configurando no Helpdesk
  1. Crie uma nova chave API usando o formulário nesta página (seção "Chaves de API")
  2. Insira a URL do webhook do n8n no campo "URL do Webhook" desta página
  3. Marque a opção "Ativar envio de webhooks"
  4. Clique em "Salvar Configurações"
4. Testando a integração
  1. Use a seção "Testar Integração" nesta página para enviar um evento de teste
  2. Verifique no n8n se o webhook recebeu os dados (nos registros de execução do workflow)
  3. Se o teste falhar, verifique as soluções de problemas abaixo
5. Exemplos de automações úteis

  1. Configure o webhook para receber eventos do tipo 'ticket_created'
  2. Adicione um nó "IF" para verificar se ticket.prioridade === 'urgente'
  3. Adicione um nó "Telegram" para enviar a mensagem
  4. Configure a mensagem com o número, título e descrição do ticket

6. Solução de problemas comuns
Problema Possíveis causas Solução
Erro "Falha ao enviar evento de teste"
  • URL do webhook incorreta ou incompleta
  • Instância do n8n não está em execução
  • Problemas de firewall ou rede
  • Verifique se a URL começa com http:// ou https://
  • Teste a URL em um navegador ou com curl
  • Verifique se a instância do n8n está rodando
  • Verifique se o firewall permite conexões na porta do n8n
Eventos não são recebidos pelo n8n
  • Webhook não está ativo no n8n
  • Problemas de configuração no endpoint
  • Verifique se o webhook no n8n está ativado
  • Consulte os logs do n8n para ver se a requisição está chegando
  • Use a ferramenta de teste de webhook do n8n para verificar o endpoint
Erros de timeout
  • Conexão lenta entre os servidores
  • Sobrecarga no servidor do n8n
  • Verifique a latência entre os servidores
  • Considere aumentar os recursos do servidor n8n
  • Verifique se há operações pesadas no workflow
7. Logs e monitoramento

Para diagnóstico mais detalhado, verifique os logs do sistema:

# Logs do Django (contém mensagens detalhadas sobre eventos enviados)
/var/log/django/helpdesk.log

# Logs do n8n 
/var/log/n8n/n8n.log (ou conforme configurado na sua instalação)
